# OctoWoW VF

Pack manuel pour mettre OctoWoW en francais.

## Installation

Telechargez :

```text
patch-6.mpq
speech.MPQ
```

Fermez le jeu, puis copiez les fichiers comme ceci :

```text
patch-6.mpq -> D:\OctoWoW\Data\patch-6.mpq
speech.MPQ  -> D:\OctoWoW\Data\patch-7.mpq
```

Important : copiez `speech.MPQ`, puis renommez la copie en `patch-7.mpq`.

Ouvrez ensuite :

```text
D:\OctoWoW\WTF\Config.wtf
```

Ajoutez ou remplacez la ligne :

```text
SET locale "frFR"
```

Lancez le jeu.

Si du contenu reste en anglais, fermez le jeu puis supprimez le dossier :

```text
D:\OctoWoW\WDB
```
